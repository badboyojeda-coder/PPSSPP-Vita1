# Plan de portabilidad del núcleo PPSSPP

1. Obtener el código original de PPSSPP y sus submódulos.
2. Auditar dependencias y arquitectura.
3. Crear el objetivo de compilación para PS Vita.
4. Adaptar memoria, CPU, HLE y sistema de archivos.
5. Adaptar gráficos, audio y controles.
6. Compilar con VitaSDK.
7. Probar y depurar en hardware PS Vita.
