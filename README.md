# PPSSPP-Vita1

Proyecto experimental para portar el núcleo original de PPSSPP a PlayStation Vita.

## Objetivo
Adaptar el código fuente original de PPSSPP para crear una versión compatible con PS Vita.

## Arquitectura del proyecto
- `vita/`: código y adaptaciones específicas para PS Vita.
- `docs/`: documentación técnica y planificación.
- `.github/workflows/`: automatización de compilación y pruebas.
